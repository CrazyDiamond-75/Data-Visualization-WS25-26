\chapter{Tabular Data}
This chapter focuses on tabular data and which chart idioms to use when plotting it.
As already mentioned, tabular items are identified by one or more keys and contain a vector of values specified by the attributes.
Tabular items may also have no key, which is similar to sampled values.

\section{Common Idioms for Tabular Data}
Common idioms used for tabular data include the following.
\begin{description}
    \item[Scatterplot] A scatterplot expresses quantitative attributes.
        Channels, in this case horizontal and vertical position, are linked to the attributes.
        The mark used is commonly a point.
        Scatterplots can be used to visually express and find correlation (or lack thereof), clusters, outliers, or distribution.
        A scatterplot can be even more expressive by encoding additional attributes in other channels, such as colour, size, and shape.

    \item[Bar chart] The bar chart can be used to express keyed items with commonly one quantitative attribute.
        The mark can be a line, while the channel is commonly the length of the line.
        The key can be ordered alphabetically or by attribute value.
        Bar charts can be used to compare values between keys.
    
    \item[Stacked Bar Chart] A stacked bar chart is a variation of the bar chart, where an additional key is used to express different portions of the value plotted, e.g., consumption of food (key) by country (key).
        The additional categorical channel to differentiate between keys often is colour.

    \item[Streamgraph] A streamgraph is a generalized stacked graph, where horizontal continuity is emphasized.
        One key is still channelled vertically while the other one may be continuous or a quantitative attribute.
    
    \item[Dot/Line Chart] The dot and line charts are a form of a bar chart, where the marks are connected points.
        This can be practical, when the horizontal key is quantitative or when there is a relation between nearby keys.
    
    \item[Indexed Line Chart] Indexed line charts are line charts with another key similar to stacked bar charts.
        This key is commonly encoded with colour as another line in the graph which does not have to be stacked on top.

    \item[Gantt Chart] A Gantt chart uses lines as marks which are channelled by their horizontal length to express a duration.
        The horizontal attribute commonly is time but can be any continuous attribute.
        One key can be used to differentiate between different \emph{tasks} by stacking them vertically.

    \item[Slopegraph] A slopegraph uses two quantitative attributes, but only samples two points on the horizontal (often time) attribute.
        Each left and right sample is marked using points which are connected.
        The vertical attribute is associated with the key and shown on the left and right size of the two points.
        The change of the vertical attribute (positive or negative) is often also channelled using colour or/and size.

    \item[Parallel Coordinates] parallel coordinate charts are slopegraphs with more than two points.

    \item[Heatmap] For tables with two keys (can be continuous, e.g., space) and one quantitative attribute, heatmaps display values in a 2D matrix which is indexed by the two keys.
        Colour is used to channel the values.
        Heatmaps can be used to find clusters and outliers.

    \item[Cluster Heatmap] A cluster heatmap is a heatmap, where the keys are ordered by identified clusters.

    \item[Radial Bar Chart, Star Plot] Radial bar charts and star plots are radial bar charts.

    \item[Radar Plot] A radar plot is a radial line chart.
        Should be avoided unless the categorical or quantitative key is radial.

    \item[Pie Chart, Coxcomb Chart] Pie charts and coxcomb charts divide the area of a circle into different regions based on a categorical key.
        The size of each area is linked to the quantitative attribute to map.
        Similar to stacked bar charts, these charts can also be stacked to channel even another key.
        Small differences can be recognized easier when using coxcomb charts rather than pie charts.

    \item[Normalized Stacked Bar Chart] this chart is a stacked bar chart, where the ratio of the second key is displayed by normalizing each stacked value to full vertical height.
        Each line is equivalent to one entire pie chart.
\end{description}

\section{Dimensionality Reduction}
A lot of more complex datasets can have too many dimensions to make them visually understandable by directly visualizing them.
The goal of this section is to present different techniques, which reduce the dimensionality of the data set while keeping vital information.

\subsection{Principle Component Analysis}
Principle component analysis (PCA) is a dimensionality reduction techniques, which maps a set of \(n \in \N\)-dimensional points to a space with \(k < n\) dimensions, by eliminating \emph{less variant} dimensions.
We first have to go through some definitions.

\newcommand{\Var}{\text{Var}}
\newcommand{\Cov}{\text{Cov}}

\begin{definition}[Variance and Covariance]
    For some vector \(x \in \R^n\), we define the variance of the vector as the average square distance to the mean.

    \[\Var(x) := \frac{1}{n}\sum_{i \in [n]} (x_i - \overline x)^2\]

    \noindent
    The variance of some dataset is broadly the measure of how spread-out it is.
    The covariance is a similar measure, which instead looks at two vectors \(x, y \in \R^n\), and declares, component-wise which dimensions of both vectors tend to change dependant on each other.

    \[\Cov(x, y) := \frac{1}{n}\sum_{i \in [n]} (x_i - \overline x) \cdot (y_i - \overline y)\]

    \noindent
    We have \(\Var(x) = \Cov(x,x)\).
    Correlation is a similar measure as it is the covariance divided by the product of standard deviations.
\end{definition}

\begin{definition}[Eigenvectors and Eigenvalues]\label{def:eigen}
    Eigenvectors and eigenvalues of some symmetric real matrix \(A \in \R^{n \times n}\) are vectors \(v\) and scalars \(\lambda\), which express \(A v = \lambda v\).
    In other words, an eigenvector \(v\) only changes scale by \(\lambda\), but not direction when it is transformed using \(A\).

    Eigenvalues of \(A\) are found by solving for the roots of the characteristic polynomial.
    I.e., find \(\lambda\) such that \[0 = \det(A - \lambda I_n),\]
    
    \noindent
    where \(I_n\) is the identity matrix with dimension \(n\).
    Eigenvectors of \(A\) are then found by solving the following linear equation system for \(v \in \R^n\).

    \[(0)^n = (A - \lambda I_d) \times v\]

    \noindent
    For symmetrical matrices, all eigenvectors should be orthogonal to each other.
\end{definition}

\subsection{PCA Algorithm}
For some matrix \(X \in \R^{d \times n}\) which contains points of dimension \(d\) in \textbf{row-wise} order, we perform PCA the following way.
\begin{enumerate}
    \item Center\footnote{General standardization is optional.} each point in \(X\) by the mean dimensional value.

    \item Calculate the covariance matrix the centered \(X\).
        This can be done by filling each entry of a matrix \(\in \R^{d \times d}\) according to the covariance formula.
        Alternatively, we can just calculate \(X^TX\), as this matrix product is a product of the covariance matrix with some scalar.

    \item Find the eigenvalues and eigenvectors of this covariance matrix according to \cref{def:eigen}.

    \item Order the eigenvectors by absolute value of the corresponding eigenvalue in decreasing order.
        The first/second/... vector is now the first/second/... principal component of \(X\).

    \item Pick the first \(k < n\) principal components of \(X\) and put them \textbf{collumn-wise} in a matrix \(V \in \R^{k \times d}\).
        Each vector can also be normalized, but this is not necessary to reduce the space.

    \item Project \(X\) to the \(k\)-dimensional subspace by multiplying \(X \times V\).
\end{enumerate}

\subsection{Other Linear Dimensionality Reduction Techniques}
\begin{description}
    \item[Independent Component Analysis (ICA)] ICA is a computational method for separating a multivariate signal into additive subcomponents. This is done by assuming that at most one subcomponent is Gaussian and that the subcomponents are statistically independent from each other.

    \item[Linear Discriminant Analysis (LDA)] LDA is a method to find a linear transformation of a multi-classed dataset, which separates each class in the best way.
        It finds the directions which maximize separation between classes and projects the data set according to these directions.
\end{description}

\section{T-Distributed Stochastic Neighbour Embedding}
T-Distributed Stochastic Neighbour Embedding (t-SNE) is a statistical method for visualizing high-dimensional data by giving each point a location in 2D or 3D space.

The t-SNE algorithm comprises two main stages.
First, t-SNE constructs a probability distribution over pairs of high-dimensional objects in such a way that similar objects are assigned a higher probability while dissimilar points are assigned a lower probability.
Second, t-SNE defines a similar probability distribution over the points in the low-dimensional map, and it minimizes the Kullback–Leibler divergence\footnote{\url{https://en.wikipedia.org/wiki/Kullback\%E2\%80\%93Leibler_divergence}} between the two distributions with respect to the locations of the points in the map.

Besides iteration count and learning rate, t-SNE uses another parameter, the \emph{perplexity} \(\sigma\)---a hand-chosen parameter of t-SNE.
As the authors state, "perplexity can be interpreted as a smooth measure of the effective number of neighbours [used for each point].
The performance of SNE is fairly robust to changes in the perplexity, and typical values are between 5 and 50.".

T-SNE is really useful when you know how to interpret it and how to set the parameters in a meaningful way.
To use and interpret t-SNE effectively, choose the right perplexity, ignore the size of clusters and distances between them, differentiate between random noise and real meaning, and generate multiple plots.

\section{Uniform Manifold Approximation and Projection for Dimension Reduction}
Uniform Manifold Approximation and Projection for Dimension Reduction (UMAP) is a similar method as t-SNE, with the main difference being the inclusion of another parameter, \emph{minimum distance}, which is the minimum distance between points in low-dimensional space.
Instead of perplexity, the similar parameter is called \emph{number of neighbours}, which is the number of approximate nearest neighbours used to construct an initial high-dimensional graph.
